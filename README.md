# 🌸 Petalora — Premium Flower Shop Website

> **Flowers that say it better.**

Petalora is a modern and elegant **flower shop website** designed to create a premium online flower-shopping experience.

The website combines a soft floral aesthetic with responsive layouts and interactive JavaScript features such as flower search, category filtering, shopping cart functionality, newsletter subscription, contact forms, and custom flower creation.

## ✨ Features

### 🏠 Modern Landing Page

* Elegant hero section
* Premium flower-shop branding
* Strong call-to-action buttons
* Responsive navigation
* Search overlay
* Shopping bag counter
* Wishlist-style interaction

### 🔎 Flower Search

Users can search the flower collection by entering keywords such as:

* Roses
* Tulips
* Sunflowers
* Bouquets

Search results update dynamically without reloading the page.

### 🌹 Flower Categories

Products can be filtered by category:

* All Flowers
* Roses
* Tulips
* Sunflowers
* Bouquets

This makes it easier for customers to discover the right flowers.

### 🛍️ Shopping Cart

The website includes a functional front-end shopping cart.

Users can:

* Add flowers to cart
* View cart items
* Increase/decrease quantity
* Remove products
* View subtotal
* Track cart count
* Continue shopping
* Proceed toward checkout

### 🌸 Custom Flower Collection

One of the key features of Petalora is the ability to create custom flower products.

Users can:

1. Upload a flower image
2. Enter a flower name
3. Set a price
4. Select a category
5. Add a short description
6. Add the flower directly to the shop

Custom products are stored in the browser, allowing them to remain available during future visits from the same browser.

### 💌 Newsletter Subscription

Visitors can subscribe using their email address to receive flower-related updates and offers.

### 📩 Contact Form

The website provides a contact section where visitors can submit:

* Name
* Email address
* Subject
* Message

### 💖 Customer Testimonial

A dedicated testimonial section showcases customer feedback and builds trust with visitors.

### 📱 Fully Responsive

The website is designed to work across:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/ummehadidevs/Flower-shop-website.git
```

### 2. Navigate to the project

```bash
cd Flower-shop-website
```

### 3. Open the project

Open `index.html` in your browser.

You can also use **VS Code + Live Server** for a better development experience.

## 💾 Browser Storage

Custom flowers and shopping-related data can be maintained using browser storage.

This means the website can provide a more realistic shopping experience without requiring a backend database.

> **Note:** This is a front-end project. No real payment processing or server-side order management is included.
